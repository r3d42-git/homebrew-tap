# Homebrew Tap — retired

This experimental Homebrew tap was retired on 27 October 2026 and is no longer maintained. Its cask and Homebrew maintenance configuration have been removed, and this repository is archived.

LM Studio Status Widget remains a separate project and is unaffected by this retirement. Download the app from its [GitHub releases](https://github.com/r3d42-git/lm-studio-status-widget/releases).

If you previously added this tap, remove it with:

```bash
brew untap r3d42-git/tap
```

Removing the tap does not uninstall the widget. The repository history is retained for reference.
